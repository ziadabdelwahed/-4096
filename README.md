# Z-4096 Protocol

Z-4096 is a research-grade mnemonic encoding scheme.

## Features

- 4096-word dictionary
- 12-bit word encoding
- reversible encode/decode
- deterministic checksum
- tagged alignment hash

## Functions

- entropy_to_mnemonic()
- mnemonic_to_entropy()
- validate_mnemonic()

## Status

Experimental cryptographic research project.

Not production-wallet-ready.
